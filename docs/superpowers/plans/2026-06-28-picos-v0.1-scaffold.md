# picos v0.1 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working Bun/TypeScript scaffold for `@uulab/picos`, a tiny terminal OS for developers focused on read-only network diagnostics.

**Architecture:** Keep OS command execution behind `safeExec()` and adapters, expose platform-neutral functions from `core`, and have CLI/TUI call only core/config APIs. The TUI is a lightweight Ink dashboard; behavior-critical logic is covered with Bun tests.

**Tech Stack:** Bun, TypeScript, Ink, React, cac, Node standard library, GitHub Actions.

---

## File Structure

- `package.json`, `tsconfig.json`, `.gitignore`: project metadata, build/test scripts, TypeScript settings.
- `src/bin/picos.ts`: executable entrypoint.
- `src/cli/index.ts` and `src/cli/commands/*.ts`: command parser and command handlers.
- `src/core/*.ts`: platform-neutral network, system, ping, and doctor logic.
- `src/adapters/*.ts`: OS-specific read-only commands.
- `src/config/*.ts`: default config, schema validation, and platform-specific config file path.
- `src/tui/*.tsx`: Ink application and screens.
- `src/utils/*.ts`: safe command execution and platform helpers.
- `tests/*.test.ts`: focused Bun tests for config paths, network summary, ping commands, and doctor aggregation.
- `README.md`, `LICENSE`, `.github/workflows/ci.yml`: release-facing docs and CI.
